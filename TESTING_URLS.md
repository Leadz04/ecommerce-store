## 🚀 Quick Start

1. Start server:
   ```bash
   npm run dev
   ```

2. Open testing UI:
   ```
   http://localhost:3000/admin/shopify-tools
   ```

3. Click buttons to test!

---

## 🧪 Run Automated Tests

```bash
# Run all tests
npm test

# Run with coverage
npm run test:coverage

# Watch mode (auto-rerun on changes)
npm run test:watch
```

Then view results at: `http://localhost:3000/admin/test-results`
