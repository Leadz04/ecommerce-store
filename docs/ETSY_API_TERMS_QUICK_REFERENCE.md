# Etsy API Terms - Quick Reference Guide

> **Last Updated**: June 16, 2025  
> **Full Compliance Guide**: See [ETSY_API_TERMS_COMPLIANCE.md](./ETSY_API_TERMS_COMPLIANCE.md)

## 🚨 Critical Requirements (Must Do)

### Before Using API
- [ ] Register for Etsy Developer Account
- [ ] Submit Application Purpose and get approval
- [ ] Provide accurate, complete information
- [ ] Review and accept API Terms

### Application Requirements
- [ ] Fully functional and tested before making available
- [ ] Consistent with approved Application Purpose
- [ ] Provide monitored support email address
- [ ] Respond to seller inquiries promptly
- [ ] Have enforceable Application Terms (privacy policy, terms of service)
- [ ] Include required warranty disclaimer in Application Terms
- [ ] Display required trademark disclaimer prominently

### Data Requirements
- [ ] **Listing content**: Refresh within **6 hours** of Etsy Site
- [ ] **Other content**: Refresh within **24 hours** of Etsy Site
- [ ] Don't cache longer than necessary
- [ ] Track timestamps for all Etsy data

### Rate Limits
- [ ] Use only designated API key for Application
- [ ] Don't create multiple keys to circumvent limits
- [ ] Track API calls and respect limits
- [ ] Request increases via developer@etsy.com if needed

## ❌ Prohibited Behaviors (Never Do)

### Core Restrictions
- ❌ Replace or mimic Etsy's core functionalities
- ❌ Circumvent Etsy checkout process
- ❌ Divert sales or migrate Members from Etsy
- ❌ Drive traffic to external sites unrelated to Etsy
- ❌ Copy Etsy's look and feel
- ❌ Misrepresent affiliation with Etsy

### Data & Security
- ❌ Use API for analytics, ML, AI training, licensing, or content removal (unless authorized)
- ❌ Scrape Etsy Site or API (unless authorized)
- ❌ Request more data than minimum needed
- ❌ Transfer or commercialize API access/credentials
- ❌ Store Member ID and password combinations
- ❌ Compromise security or integrity of Etsy API/platform

### Other Prohibitions
- ❌ Create multiple Applications with same services
- ❌ Include code unrelated to Application services
- ❌ Send order/delivery tracking info without authorization
- ❌ Solicit fake or misleading reviews
- ❌ Manipulate shop statistics or metrics
- ❌ Charge for features Etsy provides free
- ❌ Reverse engineer or decompile Etsy API

## 🔄 Ongoing Compliance

- Monitor API usage and rate limits
- Keep data fresh per requirements
- Maintain good standing with Etsy
- Respond to support inquiries promptly
- Monitor application quality and feedback
- Update Application Terms and privacy policy
- Test after Etsy API updates
- Ensure regular API usage (prevent dormancy)

## ⚖️ Legal Points

- **Indemnification**: Must defend and indemnify Etsy against claims
- **Release**: Waive claims against Etsy and Etsy Members
- **Arbitration**: Disputes resolved via individual arbitration (North/South America)
- **Non-Exclusive**: Can engage in competitive arrangements
- **No Partnership**: Not Etsy's agent, employee, or partner
- **API Changes**: Etsy can change API at any time; we must adapt at our cost
