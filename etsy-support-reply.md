## Application Overview

My application is an **E-commerce Store Management Platform** that integrates with the Etsy API to help sellers manage their products, orders, and inventory across multiple channels. The platform provides a comprehensive admin dashboard where sellers can:

1. **Connect their Etsy shops** through OAuth authentication
2. **Synchronize products** bidirectionally between the platform and Etsy
3. **Sync orders** from Etsy to the platform for unified order management
4. **Manage inventory** across both platforms with automatic synchronization
5. **Export products** to CSV format compatible with Etsy's bulk import feature

## Etsy API Integration Features

The application uses the Etsy API v3 to:

- **Shop Connection**: Authenticate and connect Etsy shops using OAuth 2.0
- **Product Management**: 
  - Import listings from Etsy shops
  - Create new listings on Etsy from platform products
  - Update existing Etsy listings
  - Delete listings when needed
- **Order Synchronization**: Import orders from connected Etsy shops
- **Inventory Management**: Sync stock levels between the platform and Etsy
- **CSV Export**: Export products in Etsy-compatible CSV format for bulk operations

All API calls respect Etsy's rate limits and include proper error handling. The application also displays the required Etsy trademark disclaimer as specified in the API Terms of Use.
