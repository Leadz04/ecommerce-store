## Tips for Recording:

1. **Speak clearly and at a moderate pace** - Not too fast, not too slow
2. **Pause briefly** when switching between sections to let viewers process
3. **Use your cursor** to point to/highlight features as you mention them
4. **Keep it natural** - This is a conversation, not a presentation
5. **If you make a mistake**, pause, then continue - you can edit later
6. **Zoom in** on important UI elements if they're small
7. **Test your mic** before recording to ensure clear audio

## Optional Enhancements:

- Add **subtitles/captions** in Loom for clarity
- Use **Loom's drawing tool** to circle/highlight important features
- Add **timestamps** in the description for easy navigation
- Include a **brief text summary** in the video description
